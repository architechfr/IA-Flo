# IA-Flo — AXION

Landing de présentation AXION / IA appliquée à la maîtrise d'œuvre.

## Objectif

Présenter AXION comme un produit métier conçu depuis le terrain :
- ChantierFlow — planning et pilotage chantier
- Faisabilité PLU — analyse réglementaire opérationnelle
- IA terrain — notes, CR, mails, tableaux de suivi
- Formations IA appliquées au bâtiment

## Déploiement

Site statique : `index.html` à la racine.

Le dépôt peut être importé directement dans Vercel.
